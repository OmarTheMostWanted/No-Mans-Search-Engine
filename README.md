# No Man's Sky System Search

A command-line search tool that enumerates portal codes and generates system data with the included [`nms-galactic-map`](https://github.com/elegra1965-source/nms-galactic-map) Git submodule. It does not use a remote service or fake search data. The Node bridge loads the submodule's real generator modules and local letter-map JSON shards.

## Requirements

- Python 3.10+
- Node.js 18+ (ES modules and BigInt support)
- Git with submodule support

## Setup

Clone this branch and initialize the included generator:

```bash
git clone --branch copilot/implement-nms-system-search --recurse-submodules https://github.com/OmarTheMostWanted/No-Mans-Search-Engine.git
cd No-Mans-Search-Engine
```

If you already cloned without submodules:

```bash
git submodule update --init --recursive
```

No Python packages need to be installed. Verify the real generator integration with:

```bash
python -m unittest -v
```

## Run a search

Try a bounded search first (search duration otherwise defaults to one hour):

```bash
python cli.py --star-color blue --min-planets 5 --max-systems 500 --duration 60
```

Search sequentially from a portal code:

```bash
python cli.py --mode sequential --start-address 0807F07FFFFF --max-systems 1000 --duration 120
```

Get JSON Lines output:

```bash
python cli.py --race gek --economy-tier 3 --max-matches 20 --duration 300 --json
```

Use `python cli.py --help` for all options. Filters are case-insensitive where they accept text. Tier values are 1 (low), 2 (medium), 3 (high); the included generator's 0-based tiers are converted to these values. Galaxy numbering in this CLI is human-friendly (Euclid is 1), converted to the submodule's index (Euclid is 0).

Searches cover canonical system addresses, with the planet glyph held at zero so one system is not searched repeatedly through its 16 planet-address variants. Random search is reproducible with `--seed`. `--max-systems` and `--max-matches` bound a run; results are printed after the run ends. Results are cached in `data/systems.sqlite3` by default; disable with `--no-cache`.

## Data scope

The included upstream API derives star type, planet/moon counts, economy, conflict, race, special-system flags, coordinates, and generated names from portal code and galaxy. The upstream API does not provide biome outcomes or a sun-count field, so this CLI intentionally does not offer lush-planet or sun-count filters. The economy/conflict label text is generated by the submodule's flavor tables; tier and system traits are derived from its portal-code attributes.
